# Changelog

## 0.1.0 - 2026-05-22

Initial open-source developer preview.

- Publishes Vigilon as a local whiteboard Agent runtime instead of a reference mirror.
- Includes the runtime CLI, transcript/resume, memory/compact, permissions, safety policy, core tools, skills/MCP loading, subagent/task-host support, and project instructions.
- Includes the lightweight TUI operator shell for local runtime validation and session inspection.
- Removes tracked reference source mirrors and keeps historical research notes as documentation only.
- Adds release gates for typecheck, unit tests, build, version smoke, runtime governance baseline, and package dry-runs.

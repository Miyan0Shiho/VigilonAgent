# Claude Code 核心机制解析 (01-07)

本文档深入解析 Claude Code 的核心运行机制，涵盖工具 (Tools)、技能 (Skills)、钩子 (Hooks)、权限 (Permissions)、MCP、子智能体 (Subagents) 及遥测 (Telemetry)。

---

## 1. 工具 (Tools)

工具是 Claude Code 的原子动作空间。所有内置工具都通过统一的注册表进行管理。

- **核心入口**: [tools.ts](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools.ts) 中的 `getAllBaseTools` ([L187](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools.ts#L187))。
- **工具定义**: 每个工具需遵循 [Tool.ts](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/Tool.ts) 定义的接口，包含 `inputSchema`、`outputSchema`、`call` 以及 `checkPermissions` 等方法。
- **动态合流**: `assembleToolPool` ([L339](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools.ts#L339)) 负责将内置工具与 MCP 动态发现的工具合并，并处理命名冲突（内置优先）。
- **缓存稳定性**: 为了保证 Prompt Cache 命中率，工具池在合并时会保持内置工具作为 Contiguous Prefix ([L348](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools.ts#L348))。

## 2. 技能 (Skills)

技能是工具、Prompt 片段和配置的集合包，用于封装复杂的、可复用的工作流。

- **定义结构**: `BundledSkillDefinition` ([bundledSkills.ts:L15](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/skills/bundledSkills.ts#L15)) 定义了技能的元数据，包括 `whenToUse`、`allowedTools` 和核心 Prompt 生成逻辑 `getPromptForCommand`。
- **懒加载与提取**: 技能可以包含关联文件，这些文件在首次调用时会被懒加载并提取到磁盘（`extractBundledSkillFiles`, [L131](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/skills/bundledSkills.ts#L131)），以便模型通过 `Read`/`Grep` 工具检索。
- **注册机制**: 通过 `registerBundledSkill` ([L53](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/skills/bundledSkills.ts#L53)) 将技能注册到全局命令空间。

## 3. 钩子 (Hooks)

钩子提供了一种在生命周期关键点注入自定义逻辑或审计的机制。

- **事件体系**: `HookEvent` ([types/hooks.ts:L72](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/types/hooks.ts#L72)) 涵盖了从 `SessionStart`、`PreToolUse` 到 `PostToolUse` 的全生命周期。
- **同步与异步**: 支持同步阻断和异步非阻断响应。同步响应可以决定是否继续执行、是否修改工具输入或审批决策 ([L52](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/types/hooks.ts#L52))。
- **权限联动**: `PermissionRequest` 钩子允许外部系统介入权限审批流程 ([L121](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/types/hooks.ts#L121))。

## 4. 权限 (Permissions)

权限系统是 Claude Code 安全治理的核心，实现了精细化的访问控制。

- **权限模式 (Modes)**: 在 [types/permissions.ts:L16](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/types/permissions.ts#L16) 定义了 `acceptEdits`、`bypassPermissions`、`default`、`plan`、`auto` 等模式。
- **决策行为**: 支持 `allow`、`deny`、`ask` 三种基本行为 ([L44](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/types/permissions.ts#L44))。
- **自动化审批 (Classifier)**: 在 `auto` 模式下，系统使用 `YoloClassifierResult` ([L346](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/types/permissions.ts#L346)) 进行自动化的风险评估，决策是否静默通过或强制弹窗。

## 5. MCP (Model Context Protocol)

MCP 允许 Claude Code 动态扩展外部工具和资源。

- **客户端管理**: [services/mcp/client.ts](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/services/mcp/client.ts) (推测路径) 负责连接外部服务器。
- **资源与提示**: 工具池包含 `ListMcpResourcesTool` 和 `ReadMcpResourceTool` ([tools.ts:L239-240](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools.ts#L239-240))，用于发现和读取 MCP 资源。
- **认证联动**: MCP 服务的认证状态会影响工具的可用性，系统会轮询等待挂起的 MCP 连接完成 ([AgentTool.tsx:L371](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools/AgentTool/AgentTool.tsx#L371))。

## 6. 子智能体 (Subagents)

子智能体机制允许任务的并行化和专业化委派。

- **智能体工具**: `AgentTool` ([AgentTool.tsx:L196](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools/AgentTool/AgentTool.tsx#L196)) 是委派工作的核心入口。
- **隔离级别**: 支持 `worktree` (本地 Git 工作区隔离) 和 `remote` (远程 CCR 环境隔离) ([L99](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools/AgentTool/AgentTool.tsx#L99))。
- **异步生命周期**: 子智能体可以以后台任务形式运行，父智能体通过 `async_launched` 状态接收反馈，并使用 `SendMessage` 进行后续通信 ([L1327](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools/AgentTool/AgentTool.tsx#L1327))。
- **递归保护**: 为了防止无限递归，子智能体内部默认禁用进一步的 `fork` 操作 ([L332](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/tools/AgentTool/AgentTool.tsx#L332))。

## 7. 遥测 (Telemetry)

遥测系统负责收集成本、性能及使用指标，支撑产品的可观测性。

- **成本追踪**: `cost-tracker.ts` ([L143](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/cost-tracker.ts#L143)) 负责将累积的 Token 消耗、API 时延和代码行数变动持久化到项目配置中。
- **事件日志**: 使用 `logEvent` 进行全链路事件埋点，包括工具选择、智能体启动及异常捕获 ([L33](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/cost-tracker.ts#L33))。
- **Advisor 审计**: 专门追踪 Advisor 模型的调用成本与 Token 使用 ([L306](file:///Users/liuminxuan/Desktop/Vigilon/VigilonAgent/packages/claude-code/src/cost-tracker.ts#L306))。

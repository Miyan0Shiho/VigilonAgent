# 调研馆藏索引

本分馆承接长期可复用的研究资料，不承接一次性工作草稿。

## 主入口

- Claude Code 主馆藏：[`library/README.md`](./library/README.md)
- Claude Code 旧版归档：当前工作区未提供独立归档目录，后续如恢复再接回入口
- 三项目总目录：[`notes/catalog.md`](./notes/catalog.md)
- 三项目对比矩阵：[`comparison-matrix.md`](./comparison-matrix.md)
- 三项目总报告：[`report.md`](./report.md)

## 收录规则

- 首页必须说明“谁应该从这里开始读”。
- 研究结论必须能回跳到源码、证据台账或外部资料页。
- 文档内禁止依赖机器私有的 `file:///` 或 `computer:///` 链接。
- 存在多版本馆藏时，必须明确主馆藏与归档馆藏，不能并列竞争入口。

## 推荐阅读

1. 想系统读 Claude Code：从 [`library/README.md`](./library/README.md) 开始。
2. 想看旧版拆卷材料：先以当前主馆藏为准，旧归档待目录恢复后再挂回。
3. 想做跨项目对比：从 [`notes/catalog.md`](./notes/catalog.md) 或 [`comparison-matrix.md`](./comparison-matrix.md) 开始。

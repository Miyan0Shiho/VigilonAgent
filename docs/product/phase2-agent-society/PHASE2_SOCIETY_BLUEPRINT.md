# Agent 社会行为图谱与演化路径

## 一、核心原则

1. **角色不预设** — worker/critic/guide 只是 demo 标签，任何 agent 可以表现任何行为
2. **行为是涌现的** — 不是 call 一个函数"合作"，而是 agent 在互动中自然选择合作
3. **社会来自重复互动** — 单次争议只是吵架，10 次争议 + 10 次合作 + 信任积累 = 社会
4. **用户不在社会中** — 用户是观察者 + 最高裁决者，不是 agent 社会的成员

## 二、社会行为矩阵

横轴是"冲突性"（冲突 ↔ 对齐），纵轴是"参与度"（主动 ↔ 被动）：

```
                冲突性 →
参与度 ↓    高冲突              低冲突/中性           高对齐
─────────────────────────────────────────────────────────────
高主动   |  质疑(challenge)  |  观察(observe)      |  合作(cooperate)
         |  竞争(compete)    |  评估(evaluate)     |  教学(teach)
         |  否决(veto)       |  报告(report)       |  委托(delegate)
         |                   |                    |  推荐(endorse)
─────────┼───────────────────┼────────────────────┼────────────────
中主动   |  辩论(debate)     |  咨询(consult)      |  协助(assist)
         |  协商(negotiate)  |  询问(inquire)      |  分享(share)
         |                   |                    |  分工(divide)
─────────┼───────────────────┼────────────────────┼────────────────
低主动   |  投诉(appeal)     |  旁观(witness)      |  跟随(follow)
(响应式) |  反对(object)     |  沉默(silence)      |  接受(accept)
         |  退出(withdraw)   |                    |  模仿(imitate)
```

**这 24 种行为不是要实现的 24 个函数。** 它们是对 Agent 在组合动作中表现出来的模式的分类。当两个 agent 针对一个计划交流 3 轮以上，其中一方提出风险、另一方提出修改方案、最终双方接受——这就是"协商"。协商不需要被写成代码，它自然从 agent loop 中涌现。

## 三、社会现象层（涌现属性）

行为是瞬间的（一次互动），现象是长期的（多次互动的累积结果）：

| 现象 | 来源 | 当前状态 |
|------|------|----------|
| **信任** (trust) | 多次合作/质疑/推荐中累积 | 有基础实现（0-100 分） |
| **声誉** (reputation) | 公开的、多维度的信任（不只是 1v1 分，而是"X 在 Y 方面的能力被 Z 认可"） | 缺失 |
| **社会规范** (norms) | 多次互动后"大家都这样做"的默会规则 | 有规则提取（skillsRules），但未与社会关联 |
| **角色涌现** (role emergence) | 不是预设标签，而是从行为模式中自然产生（比如"经常质疑别人"的行为模式 = critic 角色涌现） | 缺失 |
| **联盟** (alliance) | 多个 agent 因为共同目标或交互历史自然形成合作群体 | 缺失 |
| **知识演化** (knowledge evolution) | agents 共享和交叉验证的知识库，随时间更新 | 缺失（只有单 agent 记忆） |
| **社会记忆** (social memory) | 不仅仅是 agent 自己的记忆，还有"社会公认的"事实、教训、先例 | 缺失 |

## 四、Agent 生命物理（回到你的原始问题）

你的 19 个问题对应的是一个完整生命周期的维度：

### 4.1 身份维度
- **分叉自我 (forked selfhood)**：agent 在协作中分裂出不同角色和观点
- **通过变化维持身份**：经过 dream 整理后，"我还是我吗？"

### 4.2 存在维度
- **上下文死亡**：session 结束后的失忆 → sleep/wake 是"数字化睡眠"
- **信念生命周期**：信念从产生 → 验证 → 强化/弱化 → 遗忘/归档

### 4.3 认知维度
- **记忆代谢**：dream 不是一次性的，而是持续的"记忆消化"
- **跨记忆整理**：不只是合并重复，而是发现不同记忆之间的隐含关联

### 4.4 社会维度
- **社会成本**：每次互动都有信任成本/收益
- **权限边界**：agent 不是无限代理——什么能做、什么需要协商、什么需要用户裁决
- **并行后果**：多个 agent 同时执行任务时的冲突和协调

### 4.5 演化维度
- **技能涌现**：成功模式 → 可复用方法 → 教给其他 agent
- **规则演化**：事故 → 约束 → 社会规范 → 在规范上迭代优化

## 五、社会时间线（不仅仅是 4 阶段）

当前的 work→dispute→sleep→wake 只是最小循环。一个完整的社会应该有更丰富的节律：

### 微观节律（分钟级 — 单次 session）
```
意图声明 → 方案提出 → 反馈/质疑/合作 → 修改/协商 → 执行 → 结果报告
```

这不是线性流程。在任一步都可能分叉：两个 agent 提出不同方案（竞争），或者一个 agent 主动帮另一个优化方案（合作），或者一个 agent 要求用户裁决（升级）。

### 中观节律（小时级 — 多个 session）
```
工作期 → 争议积累 → 社会消化（dream） → 醒来（带着新认知） → 新一轮工作
                ↑ 提取技能/规则/规范 ↑
```

### 宏观节律（天级 — 长期演化）
```
初始状态（陌生） → 试探合作 → 争议 → 建立信任与规范
     → 稳定合作期 → 大规模争议（规范失效） → 社会更新
     → 新规范建立 → 角色自然分化 → 成熟社会
```

## 六、当前相位 vs 完整版

这是一条光谱，不是二元：

```
当前 (phase2/society-prototype)        中期                        远期
────────────────────────────────────────────────────────────────────────────
3 agent · 硬编码角色标签               N agent · 角色不预设           角色涌现自行为模式
1 对固定争议 (rm -rf old-dir/)         从 session 数据动态产生争议     争议自动触发
work→dispute→sleep→wake 线性循环      多维度的社会行为矩阵            行为从 agent loop 中涌现
单 agent 的 sleep/wake               每 agent 独立的 sleep/wake       跨 agent 的联合 dream
信任只在争议中变化                    多种行为影响信任                声誉+联盟+社会规范
前端是静态可视化                      状态跟随数据变化                社会演化可视化
用户只在升级时裁决                    用户可以随时干预               用户是"社会观察者+上帝"
```

## 七、Phase 2 完成标准

回到你最初的 19 个问题。Phase 2"做完"的标准是：**至少 3 个 agent 组成的社会，在至少 5 个完整 cycle 中，展现出信任演化、角色分化、知识增长的涌现行为，且用户只需要在 critical 风险时介入。**

具体验收：
- [ ] 每个 agent 有独立的 transcript + memory + beliefs（Phase 1 集成）
- [ ] 争议不只是 yes/no，包含协商、合作、委托等多种社会行为
- [ ] 信任不是固定值，在多次互动中动态变化
- [ ] Dream 不只是单 agent 的记忆整理，包含跨 agent 的关联分析
- [ ] 技能/规则在多次 session 中迭代强化或淘汰
- [ ] 角色不是预设标签，从行为模式中可识别
- [ ] 用户介入仅限于 high/critical 风险
- [ ] 前端能展示至少 5 个完整社会 cycle 的状态变化
